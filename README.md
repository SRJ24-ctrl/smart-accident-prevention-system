# Smart Accident Prevention & Helmet Detection System

An intelligent embedded safety system for two-wheelers that detects unsafe 
conditions in real time and triggers automated alerts to prevent accidents.

## 🔍 Overview
Two-wheeler accidents are frequently caused by helmet non-compliance, rider 
drowsiness, and sudden imbalance. This system addresses all three proactively 
using embedded sensors and AI-based detection — acting before an accident occurs 
rather than responding after.

## ⚙️ Features
- **Helmet Detection** – ESP32-CAM detects whether the rider is wearing a helmet
- **Drowsiness Monitoring** – IR sensor tracks eye closure patterns
- **Tilt & Imbalance Detection** – MPU6050 detects abnormal vehicle movement
- **Automated Alerts** – Buzzer, LED, and ignition relay triggered on unsafe conditions

## 🛠️ Hardware Components
- Arduino Uno
- ESP32-CAM
- MPU6050 (Gyroscope + Accelerometer)
- IR Sensor
- Relay Module
- Buzzer & LED
